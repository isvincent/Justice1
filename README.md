# 正義：一場思辨之旅｜互動教學與學習網站

高中公民課程使用的繁體中文互動式哲學思辨教材。以邁可・桑德爾《正義：一場思辨之旅》相關哲學議題為架構，將 10 個單元整合在單一、可離線使用的 HTML 網站。

## 快速使用

1. 下載 `index.html`，以 Chrome、Edge、Safari 或 Firefox 開啟。
2. 選擇 10 個單元之一，進入「哲學概念 → 核心互動 → 情境審議 → 即時測驗 → 六階段探究 → 反思評量」。
3. 使用右上角「⚙️ 顯示與操作設定」調整閱讀環境。
4. 點擊「匯出學習紀錄」下載包含全部單元的 UTF-8 文字紀錄。

## 功能

- **跨裝置 RWD**：手機、平板、電腦自適應；可手動模擬不同裝置寬度。
- **七大設定**：全螢幕、音效、裝置、版面、語言、字體、色系。
- **互動學習**：滑桿、政策與倫理選擇、加權模型、角色抽取、即時回饋。
- **50 題測驗**：10 單元 × 每單元 5 題，逐題作答並顯示解析。
- **60 個探究任務**：每單元 KNOW、UNDERSTAND、COMPARE、EMPATHIZE、REFLECT、ACT。
- **反思評量**：立場量尺、反對意見、觀點修正，並可複製 AI 評量提示詞。
- **學習紀錄**：使用瀏覽器 `localStorage` 自動保存，支援複製與文字檔匯出。
- **離線可用**：無需 API Key、資料庫、套件管理或 CDN。

### 語言切換說明

繁體中文為完整教學內容語言；英文切換目前涵蓋網站主要導覽及控制文字，**哲學單元內文尚未完整英譯**。此為雙語介面基礎版，而非完整英語教材。

### 音效與全螢幕

音效使用 Web Audio API，於使用者互動後播放短提示音。部分瀏覽器、嵌入頁面或 iOS 裝置可能限制全螢幕 API；此時不影響一般操作。

### 學習資料與隱私

資料只保存在目前瀏覽器的 `localStorage`，不會自動上傳到伺服器；清除瀏覽資料可能刪除紀錄。請學生在完成學習後主動匯出備份。此網站不收集個人姓名、帳號或學習分析資料。

## 上傳 GitHub Pages

### 方法 A：GitHub 網站操作

1. 在 GitHub 建立公開儲存庫，例如 `justice-journey`。
2. 將 `index.html` 與 `README.md` 上傳到儲存庫根目錄。
3. 前往 **Settings → Pages**。
4. 在 **Build and deployment** 選擇 **Deploy from a branch**。
5. 選擇 `main` 分支及 `/(root)`，按 **Save**。
6. 部署完成後，網址通常為 `https://你的帳號.github.io/justice-journey/`。

### 方法 B：Git 指令

```bash
git init
git add index.html README.md
git commit -m "Add interactive justice learning website"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/justice-journey.git
git push -u origin main
```

再至 GitHub Pages 設定部署分支。

## 教學建議

每單元建議 2 節課（每節 50 分鐘）：第一節情境導入、哲學概念與核心模擬；第二節角色換位、案例討論、測驗與反思。形成性評量建議：概念理解 25%、論證品質 30%、觀點比較 20%、反思與行動 25%。

## 注意事項

所有人物、政策指數、加權分數及模擬情境為教學示例，不代表真實社會調查、法律結論或客觀道德評分。哲學討論應重視理由、反例、權利保障及證據。網站使用系統字型、CSS 與 Emoji 圖示，不需額外圖檔。
